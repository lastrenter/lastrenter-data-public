# nsw-bond-outcomes

⚠️ The data repo is **FLAT** — this file and `nsw-bond-outcomes.json` sit at the repo root, not
in a folder. The embed fetches `LR_DATA_BASE + '/nsw-bond-outcomes.json'`.

What share of residential rental bonds came back to the tenant **in full**, by NSW postcode.

## Regenerating

```
node ingest/nsw_bond_outcomes.js
```

Downloads the four most recent quarterly refund files into `ingest/.cache/` (skipping any already
there) and rewrites `nsw-bond-outcomes.json`. Add `--offline` to rebuild from cache without a
network call, `--quarters N` to change the pooling window, `--min-n N` to change the suppression
threshold.

⚠️ **The file URLs are discovered from the page, not constructed.** The directory is the
*publication* month, not the quarter (Q1 2026 lives under `/2026-04/`), and filenames drift
(`…_june_2025_0.xlsx`, `…_september25.xlsx`). Anything that builds URLs from a pattern will break.

## What is in the file

`state` carries the NSW baseline. `postcodes` is keyed by 4-digit postcode:

| field | meaning |
|---|---|
| `n` | refunds in the pooled window |
| `full_pct` | % returned entirely to the tenant |
| `partial_pct` | % where some was withheld |
| `none_pct` | % where none reached the tenant |
| `median_withheld` | median dollars withheld, of those where anything was |
| `median_days_held` | median tenancy length in days |

## 🔴 Framing — this is an OUTCOME rate, not a fault rate

Money paid to an agent or landlord includes entirely **legitimate** deductions: unpaid rent, real
damage, cleaning that genuinely was required.

- ✅ *"In this postcode, 71% of bonds were returned in full."*
- ❌ *"29% of landlords withheld bond."*

The second sentence is an accusation about identifiable people inferred from an accounting record.
It is exactly the exposure the defamation firms are being consulted about. The JSON carries this
warning in its own `framing` field so it travels with the data rather than living only here.

## Coverage and honesty limits

- **NSW only.** No other state publishes the agent/tenant split at usable granularity — see
  `LastRenter_BondData_Scout_Report.md` §3. Everywhere else must use the existing
  "no source for this state" chip, never "coming soon".
- **Postcode level.** Area context. Never a statement about an individual property, and it must
  not be rendered inside a property-specific claim.
- **Thin postcodes are omitted entirely**, not flagged. 306 of 599 postcodes clear the 200-refund
  threshold, covering **94.6%** of all refunds in the window. A client cannot render what it never
  received, which is deliberate.
- **Pooled across four quarters.** One quarter in a small postcode is noise, not a trend.
